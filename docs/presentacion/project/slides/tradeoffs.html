Prometheus y Grafana: ventajas y limitaciones

Ventajas

  • Estándar de facto en cloud native y formato abierto (OpenMetrics).
  • PromQL expresa tasas, cocientes y percentiles en una línea.
  • Modelo pull: up sale gratis y el servicio no depende del monitor.
  • Todo es código versionable: reglas, datasources, dashboards.
  • Bajo costo para un servicio: unos cientos de series.

Limitaciones

  • Percentiles aproximados: interpolación dentro de cada bucket.
  • Muestreo cada 5–60 s: los picos breves se suavizan.
  • Un solo nodo y retención local: para HA o largo plazo hacen falta Thanos o Mimir.
  • La cardinalidad mal controlada degrada a Prometheus.
  • Las métricas dicen qué pasa y dónde, pero no por qué: faltan trazas y logs.
