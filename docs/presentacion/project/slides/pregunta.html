Pregunta de investigación

¿Cómo detectamos que una API tiene problemas de rendimiento o errores aunque siga disponible?

Hipótesis

Las métricas de tráfico, latencia (en percentiles) y tasa de errores detectan degradaciones que un health check no ve.

Método

PoC local con Docker Compose: API instrumentada, Prometheus, Grafana y tres escenarios de carga controlados con k6.

Fuera de alcance

Kubernetes, alta disponibilidad, Alertmanager, trazas y logs. Un solo servicio, observado de punta a punta.

Proyecto final · Cloud Computing
[Integrante 1] — 1:30 a 2:15. Leer la pregunta. Aclarar el alcance: no monitoreamos infraestructura completa, sino un servicio, que es la unidad donde el usuario percibe la degradación.
