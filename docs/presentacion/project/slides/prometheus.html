Prometheus · Proyecto graduado de la CNCF (2018)

Un modelo pull sobre una base de datos de series temporales

  • Pull: Prometheus consulta /metrics de cada servicio cada N segundos. Si no puede, up = 0.
  • Modelo de datos: nombre de métrica más etiquetas (clave=valor). Cada combinación de etiquetas es una serie.
  • PromQL: lenguaje para agregar y calcular tasas, cocientes y percentiles.
  • Reglas: recording rules (precalculan) y alerting rules (umbral + duración).

Counter

Solo sube. Peticiones, errores.

Gauge

Sube y baja. Peticiones en curso, memoria.

Histogram

Cuenta observaciones por buckets. Permite percentiles agregables.

Summary

Percentiles en el cliente. No se pueden agregar entre instancias.
